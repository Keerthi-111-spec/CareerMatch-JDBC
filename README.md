# CareerMatch – Placement Eligibility Tracker

A Java + JDBC + MySQL project.

## Features
- Register Student
- Add Company
- Check Eligibility
- Apply
- Dashboard

## Technologies
- Java
- JDBC
- MySQL

## Concepts Used
- PreparedStatement
- ResultSet
- CRUD Operations
- Database Connection

## Run
1. Import into Eclipse
2. Add MySQL Connector
3. Create database
4. Run Main.java
